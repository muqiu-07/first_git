# first_git

我的第一个 Git 练习仓库，用来熟悉 `git init` → `git add` → `git commit` 的完整流程。

## 这个仓库里有什么

- `README.md` —— 就是你正在看的这份说明

## 我在这个仓库练过的命令

```bash
git init                       # 初始化仓库
git status                     # 查看当前状态
git add .                      # 把所有改动放进暂存区
git commit -m "first commit"   # 提交到本地仓库
git log --oneline              # 查看提交历史
```

## 备注

- 默认分支：`main`
- 这是一个纯本地练习仓库，暂未关联 GitHub 远程仓库
